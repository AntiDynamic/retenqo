# Product summary

Retenqo helps Android users keep selected context, remember commitments, and follow through without sending personal memory to a cloud AI service. Enable only the notification sources you choose, review suggested commitments, ask about saved memory with local inference, and approve reminders or completion updates yourself. The optional quantized language model is downloaded separately. Room data uses SQLCipher with a Keystore-protected key, and new backup exports use authenticated encryption. Retenqo's self-defined Open Innovation problem is fragmented personal context and forgotten commitments; confirm the exact organizer challenge and evaluated commit in the Hack2Skill submission before claiming official challenge alignment. The published v0.1.4 APK remains the current signed release; this source branch does not replace it. Historical test totals and current branch results are kept revision-scoped in [Testing](../docs/TESTING.md).
